Hidden by default

Kinds listed here are hidden from the resource tree by default, on every ArgoCD instance. Pick the kind explicitly from the widget's dropdown to view it anyway.

    ReplicaSets

    A ReplicaSet with no Pods is almost always an old, scaled-down revision ArgoCD keeps around for rollback history rather than anything currently running. Hidden by default; select "ReplicaSet" in the widget's kind dropdown to view them anyway.

    Debugging

    Logs each step of the kind filter (posted config, intercepted streams) to the ArgoCD tab's own console, prefixed [argocd-ui-enhancer]. Off by default — leave it off unless you're actually diagnosing something.
